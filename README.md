## Hi, I'm Kai

I like figuring out how software behaves once someone actually tries to use it. Lately that's become real work: I check API onboarding flows and install guides for people, walking through them step by step and writing down the places where things go sideways. It's careful, slightly fussy work, and I've found I enjoy it.

Away from that work, I tinker with my own automations. I like seeing an awkward routine turn into something I can leave alone for a while. There's usually another loose end to pull on.

I have a soft spot for projects with a bit of personality. I like wandering through other people's work and seeing which small decisions make it feel like theirs.

If you've got a setup guide or an onboarding path that's giving someone trouble, [come say hello](https://github.com/xnowich/xnowich/issues).
